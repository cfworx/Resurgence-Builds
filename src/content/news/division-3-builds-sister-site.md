We built a second site. **[Division 3 Builds](https://division3builds.com/)** is live as of today, and it does for The Division 3 what this site does for Resurgence: facts you can check, and builds only when they can be real.

![The Division 3 Builds home page at division3builds.com: the headline "No Division 3 builds exist yet. Here is what is confirmed." above a status board that marks the release date, platforms and setting as not announced and gameplay as not shown, and lists Massive Entertainment as the developer, the game as in production and the Snowdrop engine as reported, each with its source](/images/news/division-3-builds-home-page-status-board.webp "The status board on division3builds.com, November 17, 2026")

## Why it has no builds yet

Because nobody can make one. Ubisoft has not shown The Division 3: no gameplay, no gear, no talents, no skills. A "Division 3 build" written today could only be a guess.

So the home page opens with a status board instead: release date, platforms, setting and gameplay, each marked "not announced" until Ubisoft says otherwise, and every fact that *is* known with the source next to it. The builds go in the moment the game has real gear to build with.

## What is confirmed today

- **It exists, and Massive leads it.** Ubisoft announced The Division 3 on September 21, 2023, "which will be led by Massive Entertainment."
- **It is in production.** Executive producer Julian Gerighty said so at the New Game+ Showcase in January 2026: "This is not a secret, it's been announced," as Windows Central reported.
- **Nothing else is.** No release date, no platforms, no setting, no trailer. The [full list with every source](https://division3builds.com/everything-we-know/) is on the new site, along with a [timeline](https://division3builds.com/timeline/) and a [release date page](https://division3builds.com/release-date/) that stays honest about the word "unknown."

Our own rundown here, with what the job listings suggest and which rumors to ignore: [The Division 3: everything we know so far](/news/division-3-everything-we-know/).

## What it means for Resurgence Builds

Nothing changes here. Resurgence Builds stays about The Division Resurgence: the [builds](/builds/), the [tier list](/tier-list/), the [database](/database/) and the [build planner](/builder/). The two sites follow the same rule we already use here: a game fact comes from the game or from Ubisoft, and we never borrow numbers from one Division game for another.

If you play Resurgence because you liked The Division 2, the new site is for the day you want to know what comes next. If you found us through Division 3 searches, welcome: Resurgence is free on iPhone, Android and PC, and the [beginner guide](/guides/division-resurgence-beginner-guide/) gets you to level 40.

## Get the news without checking every week

[Division 3 Builds launch alerts](https://division3builds.com/launch-alerts/) send three emails at most: the release date, a public test, and the first real builds. Nothing in between. If you would rather follow along, the site has an RSS feed too.
