**What this means.** The game client exists in 11 languages. For Polish, Russian, Thai and Turkish, Ubisoft translates some store and marketing copy but not the game. For Indonesian, Hungarian, Arabic and Vietnamese, no official localized page was found at all. In those eight languages, the names a player sees in the game are the English ones.

### 2.1 How to read the tables

- One table per language. The URL column is the page the term was read on. Several URLs mean the term was confirmed on each.
- ubisoft.com post ids used below: 6AHbjOjyQdOayRzdUyQQn8 = Season 2 Phase 2 post (16 Sep 2026); 1R5zWiBS0MQZNcWGYkroYT = Season 2 start post (5 Aug 2026); 1dqH85Pad1ydYGwCOdlDp7 = "Now available on Steam" (5 Aug 2026); 1rUYWPgMV9hXYZ6FcLOkpX = "Play Resurgence on PC" (28 Apr 2026); 0OaDLfM9lS5xceFt1lRDA = launch community update (28 Mar 2026); 1wetWFRDXzvICd2JuTQwBO = controller layout update (18 Mar 2026); 5GVqytscyYzwEfCr8svbNL = Regional Beta patch notes (12 Jun 2023); 6MPDW2GKm4TN9GaBE4n7GJ = Regional Beta 2 dev diary (7 Nov 2023).
- **Vanguard and Field Medic** are named in a local language only in the two 2023 beta-era posts. Those translations are three years old. Treat them as likely but confirm them in the 2026 client.
- **Bulwark and Demolitionist** come from the current Steam store description (and the Season 2 Phase 2 post for Demolitionist).
- **Tech Operator is not named in any language other than English on any official page found.** The only official pages that name it are English: the launch article https://www.ubisoft.com/en-us/game/the-division/resurgence/news-updates/6jthFjnz4FcXBGUVQUCrlt (its de-de, fr-fr, es-es, es-mx, pt-br, pl-pl and it-it URLs return the English text; ja-jp, ko-kr and zh-tw return no article) and the English-only patch notes.
- **Gear set**: the only official localized use found is in a Steam news post about a cosmetic apparel set ("unlock this cool gear set while it lasts in the shop", post gid 688639887345189147). It is listed, flagged, and not confirmed as the label of the Gear Set mechanic.
- Steam news post gids, for tracing: 711153447479547541 "The Division Resurgence Is Now Available on Steam" (5 Aug 2026), 688638619235124845 "The Call has gone out" (6 Aug 2026), 688639887345189147 "Paratroopers storm the Castle in Division Resurgence" (21 Aug 2026).

### 2.6 Gaps, and the one reliable way to close them

Not verified on any official page: the localized name of **Tech Operator** (all languages); **Vanguard** and **Field Medic** in Traditional Chinese; the in-game label for **gear set** (all languages); whether the 2023 names for Vanguard and Field Medic survived to the 2026 client.

Third-party pages do not settle it. mobi.gg's French and German specialization guides list only four classes and never name Tech Operator (https://mobi.gg/fr/astuces/specialisations-the-division-resurgence/ , https://mobi.gg/de/tipps/the-division-resurgence-spezialisierungen/ , via summarizer). A BlueStacks Japanese guide writes テックオペレーター and ヴァンガード (https://www.bluestacks.com/ja/blog/game-guides/the-division-resurgence/tdrg-beginners-guide-ja.html , via summarizer), which already disagrees with Ubisoft's 2023 バンガード.

The game itself is the source: the client can be switched to each of the ten non-English languages (section 1.1). A screen recording of the Specialization screen, an OS Protocol, a gear set piece, an exotic and the code redemption screen in each language would settle every open row. That fits the site's own rule that the game is the truth.
